# Akshat Vishwakarma | Portfolio

> **Building intelligent systems. Designing meaningful experiences. Solving real-world problems.**

An interactive, high-performance personal portfolio showcasing AI/ML engineering projects, hackathon achievements, and full-stack systems. Crafted with ultra-clean modern glassmorphism, responsive typography, live telemetry, and an iridescent cybernetic background.

---

## 🌟 Highlights

- **Live GitHub Contribution Telemetry**: Syncs in real time with the GitHub REST API and contribution heatmaps.
- **Dynamic Typewriter Kinetic Typography**: Animated hero headline cycling through machine learning core specialties.
- **Glassmorphic UI System**: Frosted glass panels, translucent depth, and sleek dark aesthetic.
- **Interactive Case Study Modals**: In-depth breakdowns of flagship projects (GeneGuard, SupplyGuard AI, FitTrack AI).
- **Vercel Optimized**: Pre-configured with cache headers for seamless streaming of ambient video assets and zero latency.

---

## 🛠️ Tech Stack

- **Core**: Semantic HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Tailwind CSS, Vanilla CSS glassmorphic design tokens
- **Typography**: Google Fonts (*Montserrat*, *Inter*)
- **Icons**: Google Material Symbols Outlined
- **Telemetry**: GitHub Contributions REST API & Real-time SVG Matrix
- **Hosting**: [Vercel](https://vercel.com)

---

## 🚀 One-Click Deploy to Vercel

Deploying this portfolio to Vercel is instantaneous with zero build configuration needed:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FAkshat-vishwakarm%2Fportfolio)

### Manual Deployment:
1. Fork or clone this repository:
   ```bash
   git clone https://github.com/Akshat-vishwakarm/portfolio.git
   ```
2. Import the repository into your [Vercel Dashboard](https://vercel.com/dashboard).
3. Framework Preset: **Other** (Root directory: `./`).
4. Click **Deploy**.
